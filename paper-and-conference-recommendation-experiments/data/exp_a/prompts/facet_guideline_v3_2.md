# Facet definitions — 3.2

Use only explicit title/abstract evidence. Problem is the addressed limitation
or question; task is the operational objective; method is how it is performed;
dataset is a named data resource used or introduced; contribution is a claimed
new artifact or supported finding. These roles are not interchangeable.

Separate independent techniques and findings. An introduced artifact may occupy
method and contribution when both roles are explicit. Empty facets are valid;
do not fill them with a generic topic, input, sample description, or language.

Findings must retain their subject, polarity, uncertainty, quantities, metric,
comparison, population and necessary leading/trailing conditions. Include
negative/null results rather than keeping only benefits. Review source coverage
as well as the grounding of each existing label.

An exact quotation proves grounding, not semantic completeness or correctness.
Source defects remain visible; never silently repair the corpus. Source-quality
flags and validator scores are heuristics, not confidence probabilities. Output
remains unreviewed silver and requires independent review for accuracy claims.
