- Same 50 frozen source/reference IDs and bytes, Qwen3-8B pinned revision, NF4, greedy, thinking off, 2048 output tokens/call, seed 42.
- Every arm inherits exact R0 raw draft, usage and seed. Max 3 logical calls including draft; max 2 new repair calls.
- V changes only extraction-validator scope, not the evaluator or all policy3.2 behavior. P uses original validator; full uses V.
- P operations replace/remove/unresolved target only indexed errors; no addition or unrelated rewriting. Removal requires source ID and reason, never inferred to establish semantic correctness.

- R0 and R2 historical outputs immutable; only compare old R2 scores when model/config/cohort/scorer hashes match. Never expose reference to generator.
