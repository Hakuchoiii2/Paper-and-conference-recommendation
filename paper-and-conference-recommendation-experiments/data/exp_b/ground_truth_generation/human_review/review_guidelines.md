# Relevance judgment

Read the query and candidate evidence. Judge the candidate in relation to the
query's specific research problem and task. Method, dataset and contribution
can strengthen or weaken the association.

| Grade | Meaning |
|---|---|
| 0 | Unrelated |
| 1 | Some shared context with limited usefulness |
| 2 | Substantially related and useful to the query |
| 3 | Highly related and directly useful to the query |

Leave the grade blank when the evidence is insufficient to judge. Use Notes to
record uncertainties or the facets that drove the grade.
