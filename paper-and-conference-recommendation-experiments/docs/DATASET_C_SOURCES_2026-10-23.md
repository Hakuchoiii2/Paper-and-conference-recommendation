# Dataset sources for C: profile-to-paper recommendation

Checked 2026-10-23. Recommendation: use **Scholar Inbox** for real personalized interactions; use CiteULike-A as a smaller established implicit-feedback comparison. LACE is a method/code source, not a distinct large user-click dataset.

## 1. Scholar Inbox — strongest match

- [ACL 2025 paper](https://aclanthology.org/2025.acl-demo.30/) identifies the dataset as approximately 800k explicit ratings from over 14.3k users. This is Scholar Inbox, not arxiv-sanity. [Official dataset README](https://github.com/avg-dev/scholar_inbox_datasets) states approximately 774k explicit ratings and 556k implicit interactions; these are publisher-reported rounded counts, not counts recomputed here.
- Direct files: [rated_papers.csv](https://raw.githubusercontent.com/avg-dev/scholar_inbox_datasets/main/data/rated_papers.csv) and [implicit_interactions.csv](https://raw.githubusercontent.com/avg-dev/scholar_inbox_datasets/main/data/implicit_interactions.csv). Actual streamed HTTP checks returned **200**, lengths **35,524,300** and **24,237,168 bytes**. Headers and first three records were read; files were not retained or fully audited.
- Verified explicit header: `arxiv_id,user_id,rating,time`. Observed negative rating value `-1`. The README defines thumbs up/down semantics but does not specify positive numeric encoding; do not assume `0/1` without inspecting unique values. `arxiv_id` must be loaded as a string to preserve identifiers.
- Verified implicit header: `arxiv_id,user_id,time`. The README describes pooled actions including reading and collect/share button clicks; the CSV has no action-type column. Observed time strings include `2022-11-20 21:34:43` and fractional seconds (`2025-02-17 12:33:55.499334`); at least one sampled implicit record has an empty timestamp. No timezone is supplied in sampled values. Validate missing dates before chronological splits.
- No paper titles or abstracts occur in either interaction schema. Join arXiv identifiers to independently acquired metadata before text-profile experiments; coverage and licensing must be measured. The separate `abstract_sentences.csv` is a small sentence-label task, not a full paper metadata catalog. [Loader source](https://raw.githubusercontent.com/avg-dev/scholar_inbox_datasets/main/load_dataset.py) confirms ordinary CSV loading.
- [Dataset license](https://raw.githubusercontent.com/avg-dev/scholar_inbox_datasets/main/LICENSE): **CC BY-NC-ND 4.0**. Record this restriction; do not describe it as unrestricted open data or redistribute a modified dataset as though it had a permissive license.
- Evaluation implication: observed explicit dislikes are useful negative judgments; unobserved papers remain unlabeled. No impression lists, displayed ranks, recommendation propensities, conference-attendance labels, or questionnaire profiles are documented in these CSVs. Consequently CTR, unbiased counterfactual lift, and conference preference/attendance cannot be established from them. A chronological held-out rating experiment is feasible after timestamp/metadata checks; distinguish recorded dislikes from sampled unobserved negatives.

## 2. CiteULike-A / T — practical historical fallback

- Primary author [CDL project page](https://www.wanghao.in/CDL.htm) links [ctrsr_datasets.rar](https://www.wanghao.in/data/ctrsr_datasets.rar). Actual streamed request returned **HTTP 200, 21,019,956 bytes**; archive body was not downloaded/extracted, so its contents were not independently inventoried.
- [Released CiteULike-A README](https://github.com/js05212/citeulike-a/blob/master/README.md) reports 5,551 users, 16,980 items and 204,987 user-item pairs; [CiteULike-T release](https://github.com/js05212/citeulike-t) is an alternative release. Treat repository-reported counts as provenance, not a fresh audit.
- Independently checked [users.dat](https://raw.githubusercontent.com/js05212/citeulike-a/master/users.dat) and [raw-data.csv](https://raw.githubusercontent.com/js05212/citeulike-a/master/raw-data.csv): both **HTTP 200**. First user line is a count followed by item IDs. Actual metadata header is `"doc.id","title","citeulike.id","raw.title","raw.abstract"`. The README warns that `.dat` IDs are zero-based while `raw-data.csv` IDs are one-based. Normalize deliberately before joining.
- Feedback is implicit library membership, not explicit dislike or an exposure log. These inspected schemas contain no interaction timestamps; do not claim temporal drift evaluation from this benchmark. Titles/abstracts are already distributed, unlike Scholar Inbox. Missing interactions are unknown, not true negatives.
- No clear dataset license was established from the inspected release README/project page. Availability does not prove permission for unrestricted redistribution; retain the original citation and resolve usage terms before publishing processed copies.

## 3. LACE — profile method and small reviewer-expertise supplement

- [Official LACE repository](https://github.com/iesl/editable_user_profiles-lace) and [paper](https://arxiv.org/abs/2304.04250) provide a controllable concept-profile recommender and CiteULike preprocessing/evaluation code. The repository description says its bundled example is **CMU reviewer-paper matching**, not all six experimental datasets or production user histories. [Usage documentation](https://raw.githubusercontent.com/iesl/editable_user_profiles-lace/main/documentation/usage-cmugoldrpm.md) identifies document abstracts/keyphrases and user-profile/candidate JSON inputs.
- The original [gold-standard reviewer dataset](https://github.com/niharshah/goldstandard-reviewer-paper-match) exposes [evaluations.csv](https://raw.githubusercontent.com/niharshah/goldstandard-reviewer-paper-match/main/data/evaluations.csv), whose actual tab-separated header contains `ParticipantID`, `Paper1`–`Paper10`, `Expertise1`–`Expertise10`. These are human self-assessed reviewing expertise scores, not reading likes/dislikes. IDs refer to Semantic Scholar; participant publication profiles and paper metadata are in the repository. No event timestamps/impression logs appear in this evaluation table.
- The current original repository distinguishes **MIT code**, **CC BY 4.0 original expertise annotations**, and third-party paper metadata/text subject to their own terms. Suitable as a small auxiliary expertise-matching test, not proof of ordinary paper discovery or conference recommendation quality.

## Decision for the project

Use Scholar Inbox as C's primary real-user evaluation dataset and CiteULike-A as the fallback requiring fewer metadata acquisition steps. Build profiles only from training interactions; evaluate held-out per-user recommendations, separate cold users/items, and disclose the candidate/negative-sampling policy. Neither dataset validates conference recommendation, profile-edit satisfaction, or questionnaire-to-user mapping without additional labels or a user study.
